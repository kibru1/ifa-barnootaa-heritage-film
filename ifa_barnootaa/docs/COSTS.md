# COSTS AND COMPUTE
## Ifa Barnootaa

### 1. Production Environment
- Platform: Kaggle Notebooks
- GPU: NVIDIA Tesla T4
- Python and FFmpeg: Open-source tools

### 2. Models and Tools
- Image generation: stabilityai/sd-turbo
- Afaan Oromo TTS: facebook/mms-tts-orm
- Image animation and video assembly: FFmpeg
- Audio synthesis and mixing: Python and NumPy
- Subtitle creation: Python

### 3. Financial Costs
The production was carried out using the available Kaggle
environment and open-source software.

No paid API calls or paid model services were used in the
documented production workflow.

### 4. Compute Limitations
GPU availability and notebook session limits affected the
choice of production workflow. Animated keyframes were used
instead of a more resource-intensive video-generation model.

### 5. Cost Tracking Limitation
Exact electricity, GPU-hour, and cloud infrastructure costs
were not independently measured. No monetary cost estimate
is claimed.
